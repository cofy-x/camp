# Customer support pilot

Sponsor: Morgan, Support Lead.

- Team: three support specialists; around 40 tickets each week.
- Duration: two weeks. Capacity: 6 staff-hours per week.
- Budget: no new software purchases.
- Target: 25% fewer repeat setup questions.
- Keep customer satisfaction at its current level.
- Start with a shared setup guide before considering a chatbot.

## Measurement and approval

No customer-satisfaction baseline has been recorded yet. Count repeat setup tickets before and during the pilot, and ask the same short satisfaction question each week.

Morgan approves guide changes before specialists publish them. Report uncertainty: a two-week sample cannot prove long-term impact.
