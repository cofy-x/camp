# Document review example

These Markdown files contain synthetic business information, not customer data. Follow the [team workflow](../../docs/workflow.md) to attach or import `customer-brief.md` and `interview-notes.md`, then ask an Agent to recommend a two-week support pilot and identify missing measurements.

The original sources remain immutable; save the resulting plan in working files. Markdown is rendered directly. UTF-8 files can be viewed as source, and other attachments retain their original bytes for download.
